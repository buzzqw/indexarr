# Review of the 2026-11-13 audit

`agy.md` in the repository root is a multi-part audit of indexarr. This page
records which findings were reproduced against the code, which were rejected,
and what was changed in the same cycle. The audit file itself is not part of
the documentation set and can be removed once this review is no longer needed.

## Method

Every finding was checked against the current source, not only against the
line number in the audit. Many line references in `agy.md` are approximate or
point at a different function; the file names are usually correct. A finding
went into the change set only when it was reproducible, low risk and did not
remove an existing behaviour.

## Implemented

| Finding | Change |
| --- | --- |
| `VULN-02` — `slog.KindAny` bypasses redaction | `internal/logsafe` now redacts an `error` attribute, plus `Authorization`/`X-Api-Key` headers, standalone `Bearer` tokens, Discord webhook paths, Telegram bot tokens and JSON secret fields. Tests: `TestHandlerRedactsErrorAttributes`, `TestRedactHeadersWebhooksAndJSON`. |
| `VULN-03` — failed logins burn PBKDF2 | `internal/web/login_limiter.go` pauses an address after five consecutive failures (30 s, doubling to 15 min) and answers `429` with `Retry-After`. A browser request without credentials is a prompt, not a failure; a correct login clears the count. Tests: `TestLoginLimiterBackoffAndRecovery`, `TestUIAuthenticationPausesFailedAttempts`. |
| `BUG-01` — flood lane not released on a panic | The page reader runs inside a closure with `defer release()`, so the lane is freed even if the reader panics. |
| `BUG-03` (partial) — background jobs outlive the database | `shutdown` now waits for the routine maintenance loop, the dedupe loop, the memory trimmer and the file backfill after the HTTP server stops and before the indexer sessions and the database close. |
| `VULN-05` (partial) — database file mode | `store.Open` sets `0600` on the database and, when present, its `-wal`/`-shm` files. Backups were already created with `0600`; the systemd unit already sets `UMask=0077`. |
| `PERF-02` — selector compilation per row and field | `compileSelector` caches compiled Cascadia selectors (bounded to 4096 entries). Tests: `TestCompileSelectorCachesAndRejectsInvalid`. |
| `PERF-03` — regex compilation per value | `compileRegex` caches compiled normalisation and extractor patterns (bounded to 4096 entries). Tests: `TestCompileRegexCachesAndRejectsInvalid`. |
| `PERF-01` (partial) — quadratic tooltip labels | `internal/web/static/app.js` builds the `label[for]` map once instead of scanning every label for every control. The visible titles are unchanged. |

## Reproduced, not changed in this cycle

| Finding | Reason |
| --- | --- |
| `VULN-04` — the Torznab key also opens the admin API | Real. Fixing it needs a separate admin key, a settings field and all seven translations. Restricting the existing additional keys would break clients that use them for `/api/v2/`. This is a product decision, not a silent patch. |
| `VULN-01` — peripheral clients do not use the SSRF guard | The guard exists, but notifications, the FlareSolverr test and catalog imports deliberately accept private addresses: a webhook to Home Assistant, FlareSolverr in Docker and a definition served from the LAN are normal deployments. Blocking private IPs would break them. The URLs are administrator-configured, not attacker-supplied definition fields. |
| `BUG-02` — a live worker keeps its slot after the client leaves | The three-minute continuation is intentional: it fills the cache for the next app request and the queue limit sheds the burst. Changing the ownership model needs a separate background pool and a measurement. |
| `PERF-04`, `PERF-05`, `PERF-06`, `PERF-08`, `PERF-09`, `PERF-10`, `PERF-13` | Database batching, write-lock splitting, composite indexes and render pooling are optimization work. The project rule is features first; they need before/after measurements on a database copy before they are worth the risk. |
| `PERF-07` — the same body is parsed for each condition | Real but small: two parses per condition, not per row. It belongs with a wider evaluation-context refactor. |
| `FEAT-01` … `FEAT-19` | User-facing features. Several already exist in another form (live fragment swap, per-indexer user agent, download cache, secondary API keys); the rest are roadmap items, not defects. |

## Rejected or already present

| Finding | Evidence |
| --- | --- |
| `BUG-04` — socket leak in the IPv4 fallback | Go documents that a non-nil response with an error (a failed redirect check) already has a closed body, and the code closes it again on the error path. No leak was reproduced. |
| `BUG-05` — data race on `c.def.Meta.URLs` | The connector copies `Meta.URLs` into `mirrors` in `NewDefinitionConnector` and never reads the definition slice during a search. Only the constructor reads it. |
| `PERF-11` — live refresh reloads the whole page | The manual live search already debounces, aborts the previous request and swaps only the results fragment (`app.js`, `[data-live-search]`). The timer-driven reload remains for the Activity pages, where it is deliberate. |
| `PERF-12` — no TTL cache on expanded details pages | `downloadCache` exists with an LRU bound and a TTL and is used by the download resolver (`definition_download.go`). |
| `VULN-05` — backups are world-readable | Archive creation already uses `0600`; the systemd unit uses `UMask=0077`. Only the database file needed the explicit mode. |
| `ARCH-07` — default user agent triggers Cloudflare | Definitions can already declare the `user-agent` setting and the connector gives that indexer its own transport with the declared browser header. |

## Verification

```sh
go test ./internal/logsafe ./internal/engine ./internal/store \
  ./internal/upkeep ./internal/web ./cmd/indexarr
go vet ./...
go test ./...
```

The selector and regex caches are bounded and do not change the parse result;
the login pause is per connection address and is cleared by a success; the
database mode change is best effort, so a filesystem without `chmod` still
starts.
