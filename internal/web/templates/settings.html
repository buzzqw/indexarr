Cloudflare / FlareSolverr

When an RSS feed or a direct indexer answers with a Cloudflare challenge, indexarr retries the same request through FlareSolverr. Leave empty to disable. Jackett and Prowlarr usually handle Cloudflare themselves, and a LAN address is never routed through FlareSolverr. The indexer URL, including its API key, is sent to FlareSolverr.

The test solves https://example.com/ through the URL above; it does not save the settings and can take up to a minute.
