How legacy sources work

Jackett / Prowlarr as manager: enter the base URL (for example http://192.168.1.10:9696) and the API key. indexarr adds the manager's aggregate path automatically.

Direct Torznab indexer: enter the full endpoint (for example http://indexer:8080/api or a URL containing torznab).

Prowlarr without a search term: indexarr lists the enabled indexers and asks each Torznab feed for the latest releases, so an empty query still fills the cache.

ExtTo / TorrentGalaxy: page URLs are handled by dedicated HTML parsers, like Gextto.

RSS: enter the feed URL. Items are read for title, magnet, .torrent enclosure, size, category and date; items without a magnet or download link are ignored.
