One feed per line. Use Name | URL to set the source name; without a name the host is used. Lines starting with # are ignored. You can also paste a complete OPML document: every xmlUrl, including nested outlines, is imported. Use feed URLs, not website pages: a page URL works only if it exposes an RSS/Atom link (often /rss or /feed) or is an ExtTo / TorrentGalaxy listing supported by the built-in HTML parser.

Import rules

A feed whose URL is already configured is skipped, so re-importing the same list is safe.

Names are taken from Name | URL, from the OPML text/title, or from the host; duplicates get a numeric suffix such as example.org (2).

Invalid URLs are reported and do not stop the other feeds. The interval and the enabled flag apply to every feed created by this page.
