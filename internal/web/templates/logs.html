Where the log lives

This page keeps the last {{.MaxEntries}} records in memory; they disappear on restart or when you press Clear.

With the systemd user service the full stream is also in the journal: journalctl --user -u indexarr -f. In Docker use docker logs -f indexarr.

To see debug messages select Debug in Runtime verbosity above; no restart is needed. The log_level in indexarr.json is only the startup fallback.
